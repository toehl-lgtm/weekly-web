# Weekly Website-Entwurf

Eigenständiger, nicht veröffentlichter Gestaltungsentwurf für die neue Weekly-Markenwelt. Die bestehende Website und Rechtstexte werden nicht geändert. Lokal vom Repository-Hauptverzeichnis aus mit `python3 -m http.server` öffnen und `entwurf-2026/` aufrufen.

Der Entwurf verwendet die bisherige App-Icondatei und vorhandene App-Aufnahmen; das Bandmotiv ist eine eigenständige SVG-Webgrafik. Die Einführung und die Bandebenen in den folgenden Bereichen reagieren auf Scrollen; weitere Inhalte erscheinen beim Erreichen. Ein zusammenhängender dunkler Hintergrund verbindet die Kapitel. Bei „Bewegung reduzieren“ wird die Bewegung abgeschaltet, und ohne JavaScript bleiben alle Inhalte sichtbar. Plus Jakarta Sans liegt lokal mit ihrer Open Font License unter `assets/`.

Vor einer Übernahme auf die echte Seite: finale Aufnahmen und Schriftzug im Header aktualisieren; Texte und Funktionen gegen den Release prüfen; Abo-Informationen für die tatsächlich veröffentlichte Version ergänzen; englische Version sowie bestehende Zugänglichkeit, Navigation, Datenschutz- und Support-Funktionen vollständig übernehmen; rechtliche Angaben prüfen. Dieser Entwurf ist keine Release-Freigabe.
